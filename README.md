# VPS Initializer

Набор Bash-скриптов для автоматической первоначальной настройки и защиты чистого VPS под управлением Ubuntu.

Установка выполняется одной командой. Каждый модуль отвечает за отдельную часть настройки системы.

## Быстрый старт

Подключитесь к VPS и выполните:

```bash
curl -fsSLo /tmp/vps-init.sh https://raw.githubusercontent.com/khetaghub/vps-initializer/install.sh && sudo bash /tmp/vps-init.sh
```

Скрипт загрузит проект в `/opt/vps-initializer` и последовательно выполнит все доступные модули.

> **Важно:** предназначен для первоначальной настройки чистого VPS. Повторная установка на уже настроенную систему не поддерживается.

## Модули

| Модуль              | Назначение                               |
|---------------------|------------------------------------------|
| `install.sh`        | Оркестратор установки                    |
| `01-system.sh`      | Подготовка и обновление системы          |
| `02-users.sh`       | Создание администратора и настройка прав |
| `03-ssh.sh`         | Настройка и защита SSH                   |
| `04-firewall.sh`    | Настройка UFW                            |
| `05-fail2ban.sh`    | Защита SSH от подозрительных подключений |

### 01 — System

- Обновление индекса APT и установленных пакетов.
- Автоматические обновления безопасности без перезагрузки.
- Часовой пояс `Europe/Moscow`.
- Синхронизация времени через NTP.
- Проверка применённых настроек.

### 02 — Users

- Создание администратора с домашней директорией и Bash.
- Предоставление прав `sudo`.
- Установка пароля.
- Добавление публичного SSH-ключа.
- Настройка прав на `.ssh` и `authorized_keys`.
- Проверка созданного пользователя.

### 03 — SSH

- Интерактивный выбор SSH-порта.
- Резервное копирование конфигурации.
- Отключение root-входа и парольной аутентификации.
- Настройка ограничений аутентификации.
- Проверка конфигурации и ручное подтверждение нового подключения.
- Восстановление прежней конфигурации при ошибке.

### 04 — Firewall

- Установка и включение UFW.
- Запрет входящих соединений по умолчанию.
- Разрешение исходящих соединений.
- Автоматическое определение и открытие SSH-порта.
- Поддержка IPv4 и IPv6.
- Проверка итоговых правил.

### 05 — Fail2ban

- Защита SSH через Fail2ban.
- Режим обнаружения `aggressive`.
- Блокировка после 3 неудачных попыток за 24 часа.
- Бессрочная блокировка IP.
- Интеграция с UFW.
- Проверка действующих настроек.

> При бессрочных блокировках сохраняйте доступ к консоли VPS у провайдера на случай блокировки собственного IP.

## Логирование

Каждая операция выводит краткий статус:

```text
[install > system] Обновление пакетов...
[install > system] Обновление пакетов — успешно
```

Подробный технический журнал сохраняется в:

```text
/opt/vps-initializer/install.log
```

При ошибке выполнение установки останавливается.

## Локальный запуск

Запуск всех модулей:

```bash
sudo bash install.sh
```

Запуск отдельного модуля:

```bash
sudo bash modules/01-system.sh
```

## Требования

- Ubuntu 24.04 LTS.
- Права `root` или `sudo`.
- Подключение к интернету.
- Доступ к SSH и консоли.

## Предупреждение

Скрипты изменяют системные настройки, пользователей, SSH и firewall. Перед запуском убедитесь, что имеете возможность
восстановить доступ к серверу.

Проект находится в разработке. Используйте его на собственный риск.
